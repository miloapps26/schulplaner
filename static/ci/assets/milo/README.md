# Milo Mark Assets

Diese Dateien sind aus dem offiziellen Milo-Zeichen `../milo-mark.svg` abgeleitet.
Das Motiv bleibt unveraendert: dunkle Milo-Figur, sichtbarer Milo-Schriftzug,
Teal-/Blau-Akzente.

## Varianten

- `milo-mark-white.svg`: Vektor mit weissem Hintergrund.
- `milo-mark-alpha.svg`: Vektor mit transparentem Hintergrund.
- `milo-mark-white-256.png`, `512`, `1024`: PNG mit weissem Hintergrund.
- `milo-mark-alpha-256.png`, `512`, `1024`: PNG mit transparentem Hintergrund.
- `milo-mark-white-512.jpg`, `1024`: JPG mit weissem Hintergrund.

JPG kann technisch keinen Alphakanal speichern. Fuer transparente Verwendung
immer SVG alpha oder PNG alpha nutzen.
